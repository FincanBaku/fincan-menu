# Бесплатное QR-меню для кафе / ресторана

Простой сайт-меню, как платные QR-меню, но бесплатно:
- **Хостинг:** GitHub Pages (0 ₼)
- **Редактирование меню:** Google Таблица (0 ₼). Поменяли цену в таблице — через несколько минут она обновилась на сайте.

Сайт лежит в папке [`docs/`](docs).

---

## 1. Google Таблица (ваша «админка»)

> Таблица для Fincan уже создана: https://docs.google.com/spreadsheets/d/1Y28fSl8JFw06vk7G9p_6o93zfG2U2wvDTnxKA5BIVyk/edit
> и подключена в `docs/config.js`. Нужно только открыть доступ: **Настройки доступа → Все, у кого есть ссылка → Читатель**.
> Если таблица недоступна, сайт показывает меню из `docs/menu.csv`.

Как сделать новую таблицу с нуля:

1. Откройте https://sheets.new
2. Первая строка (заголовки) — **ровно такие**:

| category | name | description | price | photo | available |
|---|---|---|---|---|---|
| Салаты | Цезарь | Курица, пармезан | 9 | ссылка на фото | yes |

- `category` — раздел меню (Завтраки, Напитки…). Порядок разделов = порядок в таблице.
- `price` — просто число.
- `photo` — фото блюда: либо путь к файлу в папке `docs/img/` (например `img/p227.jpg`), либо прямая ссылка на картинку. Пусто — покажется первая буква названия.
- `available` — `no` / `нет` / `yox`, если блюда сейчас нет (оно станет серым). Удалять не обязательно.

Можно просто скопировать содержимое [`docs/menu.csv`](docs/menu.csv): **Файл → Импорт → Загрузить**.

3. **Настройки доступа → Все, у кого есть ссылка → Читатель**.
4. В `docs/config.js` в поле `sheetCsvUrl` вставьте:
   `https://docs.google.com/spreadsheets/d/ID_ТАБЛИЦЫ/gviz/tq?tqx=out:csv&headers=1`
   (ID — часть ссылки на таблицу между `/d/` и `/edit`).

Там же в `config.js` укажите название кафе, телефон, адрес, Instagram, WhatsApp, цвет и валюту.

> После изменения таблицы Google обновляет опубликованный CSV примерно за **1–5 минут**.

### Как добавить новое фото

> Если у блюда в таблице колонка `photo` пустая, сайт сам берёт фото из `docs/menu.csv` в репозитории (по названию блюда).

1. Уменьшите фото (до ~800 px, например на squoosh.app) — так меню быстрее открывается на телефоне.
2. На GitHub откройте папку `docs/img` → **Add file → Upload files** → загрузите файл.
3. В таблице в колонке `photo` напишите `img/имя-файла.jpg`.

> Текущее меню **Fincan Çay Evi** (43 позиции, 6 разделов) и все фото уже перенесены из Loyallo в `docs/menu.csv` и `docs/img/`.

## 2. Опубликуйте сайт (GitHub Pages)

1. Репозиторий на GitHub → **Settings → Pages**
2. *Source*: **Deploy from a branch** → ветка (например `main`) → папка **`/docs`** → Save.
3. Через 1–2 минуты сайт будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

> На бесплатном тарифе GitHub Pages работает только для **публичных** репозиториев.
> Альтернатива для приватного репозитория — **Netlify** или **Cloudflare Pages** (тоже бесплатно): просто перетащите папку `docs` на app.netlify.com/drop.

## 3. QR-код для столиков

Сгенерируйте QR-код на адрес сайта (например на qr-code-generator.com или в Canva) и распечатайте.
QR ведёт на сайт, а меню берётся из таблицы, поэтому **при изменении меню QR перепечатывать не нужно**.

## Свой домен (по желанию)

Например `menu.mycafe.az`: в Settings → Pages → Custom domain. Платите только за домен (~10–20 $/год).
