# Бесплатное QR-меню для кафе / ресторана

Простой сайт-меню, как платные QR-меню, но бесплатно:
- **Хостинг:** GitHub Pages (0 ₼)
- **Редактирование меню:** Google Таблица (0 ₼). Поменяли цену в таблице — через несколько минут она обновилась на сайте.

Сайт лежит в папке [`docs/`](docs).

---

## 1. Google Таблица — здесь вы меняете меню

**Таблица Fincan:** https://docs.google.com/spreadsheets/d/12zG4KLU3Nz4eOA85Nh1kl5mBZL65dH-nlhilVnlR158/edit
(подключена в `docs/config.js`; доступ «Все, у кого есть ссылка → Читатель» должен оставаться включён).
Изменения появляются на сайте через **1–5 минут**. Если таблица недоступна, сайт показывает запасное меню из `docs/menu.csv`.

### Колонки
| Колонка | Что писать | Пример |
|---|---|---|
| `category` | Раздел меню. **Порядок разделов и блюд на сайте = порядок строк в таблице** | `ÇAY SETLƏRİ` |
| `name` | Название блюда | `Çay + Şokolad` |
| `description` | Состав / описание (можно пусто) | `Çay, Qəlyan, Şirniyyat` |
| `price` | Только число, дробь через точку | `1.5` |
| `photo` | `img/имя-файла.jpg` из папки `docs/img/` или ссылка `https://…` (пусто — первая буква названия) | `img/p240.jpg` |
| `available` | `yes`; если блюда сейчас нет — `no` / `yox` (станет серым с пометкой «bitib») | `yes` |
| `badge` | Метка: `hit` (🔥 Ən çox sifariş), `tovsiye` (⭐ Tövsiyə edirik), `yeni` (✨ Yeni) или пусто | `hit` |
| `show` | `yes` — показывать на сайте, `no` — скрыть. **Строка остаётся в таблице (базе)**, её можно вернуть в любой момент | `yes` |
| `name_ru`, `name_en` | Название на русском / английском (пусто — показывается азербайджанское) | `Чай + шоколад` |
| `description_ru`, `description_en` | Описание на русском / английском | `Чай и кальян` |
| `category_ru`, `category_en` | Название раздела на русском / английском (достаточно заполнить в первой строке раздела) | `Напитки` |

- В колонках `available`, `badge`, `show` удобно сделать **выпадающие списки**: выделите колонку → **Данные → Проверка данных → Раскрывающийся список** (`yes, no` / `hit, tovsiye, yeni` / `yes, no`).
- Сайт читает только **первый лист** таблицы. Дополнительные листы (памятки и т.п.) добавляйте после него.
- Блюда с меткой автоматически попадают в ленту **⭐ Populyar** вверху меню (сначала `hit`, потом `tovsiye`, потом `yeni`).
- Регистр и пробелы в заголовках не важны. **Свои колонки** (заметки, себестоимость и т.п.) можно добавлять справа — сайт их не покажет и не сломается.
- **Новое блюдо:** вставьте строку в нужное место. **Убрать с сайта:** `show` = `no` (не удаляйте строку — она пригодится). **Переставить раздел:** перенесите его строки выше/ниже.
- Тексты меток и других надписей на каждом языке меняются в `docs/config.js` → `texts.az` / `texts.ru` / `texts.en`.

### Языки (AZ / RU / EN)
Сайт всегда открывается на азербайджанском, в шапке есть переключатель **AZ · RU · EN** (выбор гостя запоминается).
Переводы блюд берутся из колонок `*_ru` / `*_en`. Пустая ячейка — показывается азербайджанский текст.
Поиск работает сразу на всех языках и без учёта ç/ş/ə/ı: «cay» найдёт «Çay», «чай» — тоже.

Таблица уже содержит переводы всех блюд на русский и английский. Если создаёте новую таблицу —
импортируйте `docs/menu.csv` (там тоже есть все переводы, см. «Если понадобится новая таблица»).
Пока колонок `*_ru` / `*_en` в таблице нет, сайт берёт переводы из `menu.csv` по названию блюда.

### Как добавить новое фото
1. Уменьшите фото (до ~800 px, например на squoosh.app) — так меню быстрее открывается на телефоне.
2. На GitHub откройте папку `docs/img` → **Add file → Upload files** → загрузите файл.
3. В таблице в колонке `photo` напишите `img/имя-файла.jpg`.

Для существующих фото рядом лежат лёгкие версии `.webp` (на ~30% меньше). Сайт сам пробует `.webp`, а если его нет — берёт `.jpg`,
поэтому в таблице всегда пишите `.jpg`, ничего переделывать не нужно.

> Если ячейка `photo` пустая, сайт берёт фото из `docs/menu.csv` по названию блюда. Метки `badge` и переводы берутся из `menu.csv`, только если в таблице вообще нет такой колонки.
> Если Google отвечает дольше 3,5 секунды, сайт сразу показывает `menu.csv`, а когда таблица загрузится — тихо обновляет меню.

### Если понадобится новая таблица
Импортируйте `docs/menu.csv` в https://sheets.new (**Файл → Импорт**), включите доступ «по ссылке → Читатель»
и вставьте в `docs/config.js` → `sheetCsvUrl`: `https://docs.google.com/spreadsheets/d/ID_ТАБЛИЦЫ/gviz/tq?tqx=out:csv&headers=1`
(ID — часть ссылки между `/d/` и `/edit`).

## 2. Опубликуйте сайт (GitHub Pages)

1. Репозиторий на GitHub → **Settings → Pages**
2. *Source*: **Deploy from a branch** → ветка (например `main`) → папка **`/docs`** → Save.
3. Через 1–2 минуты сайт будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

> На бесплатном тарифе GitHub Pages работает только для **публичных** репозиториев.
> Альтернатива для приватного репозитория — **Netlify** или **Cloudflare Pages** (тоже бесплатно): просто перетащите папку `docs` на app.netlify.com/drop.

## 3. QR-код для столиков

Готовые QR-коды и карточка A6 для столов — в папке [`qr/`](qr). Перегенерировать: `python3 qr/make_qr.py`.
QR ведёт на сайт, а меню берётся из таблицы, поэтому **при изменении меню QR перепечатывать не нужно**.

## Свой домен (по желанию)

Например `menu.mycafe.az`: в Settings → Pages → Custom domain. Платите только за домен (~10–20 $/год).

## Обновления, кэш и офлайн

На сайте работает service worker (`docs/sw.js`): после первого открытия меню грузится мгновенно и **работает даже без интернета**
(показывается последняя сохранённая версия). При этом при каждом открытии сайт проверяет обновления, поэтому
**никаких меток версий менять не нужно** — правки в `app.js`, `style.css`, `config.js` гости увидят при следующем открытии.

## Статистика

Подключён бесплатный [GoatCounter](https://www.goatcounter.com) — панель: https://sarkhan999.goatcounter.com.
- Строка `/menu/` — **просмотры меню** (каждое открытие или обновление страницы).
- Строки `item/<блюдо>` и `lang/ru`, `lang/en` — **события**, а не просмотры: какие блюда открывали и кто переключал язык.
  Каждое событие считается не больше одного раза за визит (повторное открытие того же блюда не добавляет счётчик),
  возврат на AZ не считается.
- Счётчик не использует cookies.

**Чтобы ваши собственные проверки не попадали в статистику**, откройте один раз на каждом своём телефоне/браузере
ссылку https://fincanbaku.github.io/menu/#toggle-goatcounter и подтвердите отключение.
Повторное открытие этой ссылки включает подсчёт обратно.

## Превью ссылки

Когда ссылку на меню отправляют в WhatsApp / Telegram / Instagram, показывается карточка с картинкой `docs/img/og.jpg`
(название и описание — теги `og:*` в `docs/index.html`). Ссылку на конкретный раздел можно взять из адресной строки,
например `https://fincanbaku.github.io/menu/#cat-ickiler`.
