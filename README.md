# Бесплатное QR-меню для кафе / ресторана

Простой сайт-меню, как платные QR-меню, но бесплатно:
- **Хостинг:** GitHub Pages (0 ₼)
- **Редактирование меню:** Google Таблица (0 ₼). Поменяли цену в таблице — через несколько минут она обновилась на сайте.

Сайт лежит в папке [`docs/`](docs).

---

## 1. Google Таблица — здесь вы меняете меню

**Таблица Fincan:** https://docs.google.com/spreadsheets/d/1y60vCIuNcuwYnO4Q8PF8gTutTf3BiRnemnMVoWmIxTM/edit
(подключена в `docs/config.js`; доступ «Все, у кого есть ссылка → Читатель» должен оставаться включён).
Изменения появляются на сайте через **1–5 минут**. Если таблица недоступна, сайт показывает запасное меню из `docs/menu.csv`.

### Колонки
| Колонка | Что писать | Пример |
|---|---|---|
| `category` | Раздел меню. **Порядок разделов и блюд на сайте = порядок строк в таблице** | `ÇAY SETLƏRİ` |
| `name` | Название блюда | `Çay + Şokolad` |
| `description` | Состав / описание (можно пусто) | `Çay, Qəlyan, Şirniyyat` |
| `price` | Только число, дробь через точку | `1.5` |
| `photo` | `img/имя-файла.jpg` из папки `docs/img/` или ссылка `https://…` (пусто — первая буква названия) | `img/p240.jpg` |
| `available` | `yes`; если блюда сейчас нет — `no` / `yox` (станет серым с пометкой «bitib») | `yes` |
| `badge` | Метка: `hit` (🔥 Ən çox sifariş), `tovsiye` (⭐ Tövsiyə edirik), `yeni` (✨ Yeni) или пусто | `hit` |

- Блюда с меткой автоматически попадают в ленту **⭐ Populyar** вверху меню (сначала `hit`, потом `tovsiye`, потом `yeni`).
- Регистр и пробелы в заголовках не важны. **Свои колонки** (заметки, себестоимость и т.п.) можно добавлять справа — сайт их не покажет и не сломается.
- **Новое блюдо:** вставьте строку в нужное место. **Удалить:** удалите строку. **Переставить раздел:** перенесите его строки выше/ниже.
- Тексты меток и других надписей меняются в `docs/config.js` → `texts`.

### Как добавить новое фото
1. Уменьшите фото (до ~800 px, например на squoosh.app) — так меню быстрее открывается на телефоне.
2. На GitHub откройте папку `docs/img` → **Add file → Upload files** → загрузите файл.
3. В таблице в колонке `photo` напишите `img/имя-файла.jpg`.

> Если ячейка `photo` пустая, сайт берёт фото из `docs/menu.csv` по названию блюда. Метки `badge` берутся из `menu.csv`, только если в таблице вообще нет колонки `badge`.

### Если понадобится новая таблица
Импортируйте `docs/menu.csv` в https://sheets.new (**Файл → Импорт**), включите доступ «по ссылке → Читатель»
и вставьте в `docs/config.js` → `sheetCsvUrl`: `https://docs.google.com/spreadsheets/d/ID_ТАБЛИЦЫ/gviz/tq?tqx=out:csv&headers=1`
(ID — часть ссылки между `/d/` и `/edit`). После правки `config.js` обновите метку `?v=` (см. «Обновления и кэш»).

## 2. Опубликуйте сайт (GitHub Pages)

1. Репозиторий на GitHub → **Settings → Pages**
2. *Source*: **Deploy from a branch** → ветка (например `main`) → папка **`/docs`** → Save.
3. Через 1–2 минуты сайт будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

> На бесплатном тарифе GitHub Pages работает только для **публичных** репозиториев.
> Альтернатива для приватного репозитория — **Netlify** или **Cloudflare Pages** (тоже бесплатно): просто перетащите папку `docs` на app.netlify.com/drop.

## 3. QR-код для столиков

Готовые QR-коды и карточка A6 для столов — в папке [`qr/`](qr). Перегенерировать: `python3 qr/make_qr.py`.
QR ведёт на сайт, а меню берётся из таблицы, поэтому **при изменении меню QR перепечатывать не нужно**.

## Свой домен (по желанию)

Например `menu.mycafe.az`: в Settings → Pages → Custom domain. Платите только за домен (~10–20 $/год).

## Обновления и кэш

GitHub Pages разрешает браузеру хранить файлы сайта 10 минут. Чтобы гости сразу получали новую версию,
в `docs/index.html` у файлов есть метка версии: `style.css?v=…`, `app.js?v=…`, `config.js?v=…`.
**При изменении этих файлов меняйте метку** (например, на текущую дату и время).
Меню из таблицы и `menu.csv` всегда загружаются свежими.
